## 3. 本步踩到并已修掉的坑（重要）

### 3.1 Gradle 守护进程 OOM 崩溃

现象：`Gradle build daemon disappeared unexpectedly`，`hs_err_pid*.log` 里是
`Native memory allocation (mmap) failed to map 65536 bytes … Failed to commit metaspace`。
原因：`-Xmx3072m` + Kotlin daemon + kapt worker + 系统只剩 ~4.5 GB，native metaspace 分配失败。
处置（已写进 `gradle.properties`）：
```
org.gradle.jvmargs=-Xmx2048m -XX:MaxMetaspaceSize=896m -Dfile.encoding=UTF-8
org.gradle.parallel=false
org.gradle.workers.max=2
kotlin.daemon.jvmargs=-Xmx1280m
```

### 3.2 单测 worker 起不来：`找不到或无法加载主类 GradleWorkerMain`

现象：编译全部成功，`testDebugUnitTest` 里子进程直接报类找不到。
真正的根因不是类路径写错，而是 **`GRADLE_USER_HOME` 是中文路径**（`F:\安卓\.android-build\gradle-user-home`）：
Gradle 给测试 worker 写 `@argfile` 时用 `file.encoding=UTF-8`，而 Java launcher 读 argfile 用
`sun.jnu.encoding=GBK` → 中文路径被解成乱码 → worker jar 加载不到。
处置：加 ASCII 联接 `F:\gh → F:\安卓\.android-build\gradle-user-home`，环境脚本里
`GRADLE_USER_HOME=F:\gh`（联接不复制文件，6.7 GB 缓存原地复用，无需重下）。
**这条已写回 `docs/02` 的排障表；以后任何工具链路径都不许带中文。**
