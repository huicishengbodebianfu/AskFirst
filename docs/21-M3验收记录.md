## 4. 真机上发现并修掉的两个缺陷（验收驱动）

1. **保存/删除的回执会被列表刷新抹掉**：`HomeViewModel.refresh()` 尾部固定 `error = null`，
   场景删除被拒时红字一闪就没。修复：拆出 `refreshSilently()`（不清提示），三个场景操作改调它。
   → M3-11 的拒绝文案这才显示出来。
2. **编辑器保存返回后首页列表不刷新**：要重启 App 才看到新卡。修复：HomeScreen 挂
   `ON_RESUME` 生命周期观察，回来就 `refreshSilently()`。
   → M3-02/M3-12 的「保存后立刻出现 / 删除后立刻消失」。

两个都是「先真机跑一遍才知道」的问题，正是验收清单存在的意义。

## 5. 决策与偏差

1. **内置场景只读**是硬规则（启动种子按 id 覆盖 builtin），菜单里不提供「改/删」，
   修改路径只有「复制为自建」——UI 与仓库双重拦截。
2. **导入落库永远 builtin=false**，id 撞车换新 id 不改名（朋友间传场景最常见的失败就是 id 相同）。
3. **导出用 ACTION_SEND 文本**（与 M2 导出 MD 同一套路），不落盘文件；文件级分享留给 M5 SAF 管线。
4. **导入用 SAF `OpenDocument`**（application/json + text/*）；HONOR 上它落到系统「文件管理·最近」，
   从抽屉「下载内容」能选到推入 Download 的文件——真机走通。
5. 编辑器排序用「上移」按钮而非拖拽（自用频度低，实现代价高）。
6. 真机中文输入受限（百度输入法无法 adb 注入、ADBKeyboard 未装），场景名/题干用 ASCII 验证流程；
   中文文案的正确性由单测（校验文案、导出模板逐字）锁定——同一代码路径。
