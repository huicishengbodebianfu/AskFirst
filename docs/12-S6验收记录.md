## 5. 这轮踩到的坑

1. **「看单子」偷偷调了模型**：第一版 `SheetViewModel` 在"单子为空"时也自动出单，结果我打开那个"故意没出单"的会话做拦截截图时，
   它自己把单子填满了（假引擎把 7 条灌了进去），**拦截证据当场失效**。改成"只有 `build=true`（点了够了）才出单"。
   顺带说清语义：预览不该有副作用。
2. **HONOR 装完 APK 会弹「安装成功」对话框**，挡住后续 `am start`：这次第一张截图拍到的是系统安装完成页。
   处置：`adb shell input keyevent BACK` + `force-stop com.android.packageinstaller` 之后再启动。
3. 又一次遇到"logcat 里没有我的日志"：`am start` 打在**已在前台的实例**上时，新 intent 未必走到 `onCreate`；
   用 `force-stop` → `logcat -c` → `am start` 的固定顺序才稳定。

## 6. 与施工清单的偏差

- 出单在"进入确认单页"时自动触发（`build=true`），没有单独一个"出单中…"页面；用页面内进度条代替。
- 「重新生成」= 顶栏「重新出单」，会保留手改条目（M1-07 的"改了确认单必须能重跑"）。
- 复制到剪贴板是真的写系统剪贴板（`LocalClipboardManager`），但**设备上没法可靠读回验证**（`dumpsys clipboard` 在 HONOR 上不可用），
  所以逐字验证是靠 `exportPrompt()` 的日志而不是剪贴板回读。
