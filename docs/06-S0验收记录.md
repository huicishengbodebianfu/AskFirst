## 3. 环境结论（写回 `02-环境与版本矩阵.md` 的坑）

1. **AGP 8.13.1 与 Gradle 8.9 互斥**：在项目目录里跑 `gradle wrapper` 会在配置阶段炸
   （`AndroidProblemReporterProvider` / `InternalProblems` 缺失）。正确做法：在空目录生成 wrapper 再拷回项目根，
   `distributionUrl` 改腾讯镜像。
2. **镜像全部命中**：aliyun 的 `gradle-plugin` / `google` / `public` 三个源解析了 AGP、Kotlin 2.2.20、
   Compose BOM，一次都没回落到 `google()` / `mavenCentral()`。
3. **主题**：未引 `com.google.android.material`，`Theme.Material3.*` 不存在 → 用
   `android:Theme.Material.Light.NoActionBar`，配色全交给 Compose `colorScheme`。
4. **无害告警**：`Unable to strip libandroidx.graphics.path.so`（未配 NDK strip，APK 正常）。
5. **C 盘零写入**：构建前后对 `C:\Users\sengz\.gradle` 全量快照比对，差异 0（185 vs 185）；
   `~/.android`、`~/.m2`、`%LOCALAPPDATA%\Android` 同样 0 新增；`GRADLE_USER_HOME` 已增长到 6.76 GB，全在 F:。
6. **设备侧限制**：HONOR 上 `uiautomator dump` 被系统 kill（exit 137），`screencap` + 像素采样可用。
   后续 UI 验收以截图为证，不依赖 uiautomator。

## 4. 遗留动作

- `gradlew.bat` 依赖 `JAVA_HOME`：**每个新 shell 必须先 source** `F:\安卓\.android-build\askfirst-env.ps1`。
- 构建只走 `F:\askfirst`（ASCII 联接），不要用 `F:\安卓\AskFirstApp` 直接构建。
- M1 发布前补 release keystore（`02 §7`），当前是 debug 签名。
