# 网络与证书配置（network_security_config）

日期：2026-11-24 · 对应改动：允许 user CA（全构建）+ debug 额外放行明文与内置 magpie CA

## 1. 三层配置

| 构建 | 文件 | 允许明文 | 信任的根证书 | 用途 |
|---|---|---|---|---|
| main（release 生效） | `app/src/main/res/xml/network_security_config.xml` | ❌ | `system` + **`user`** | 正常用户（DeepSeek/OpenAI 等 https）；想让 release 也能连自建网关时，把网关 CA 装进手机"用户证书"即可 |
| debug | `app/src/debug/res/xml/network_security_config.xml`（同名覆盖 main） | ✅ | `system` + `user` + **`@raw/magpie_ca`** | 本机假 SSE 服务（`adb reverse` 127.0.0.1）、局域网 HTTP 网关、自签 magpie 网关（不用装证书） |
| manifest | `app/src/main/AndroidManifest.xml` | — | — | `android:networkSecurityConfig="@xml/network_security_config"`；debug 的 manifest 不再重复声明（用资源覆盖） |

内置 CA：`app/src/debug/res/raw/magpie_ca.pem`（来自 `D:\系统管理\magpie-ca.pem`，SHA-256 `03AD378A…47AD1`）。
**只在 debug 里**，release 不打包它——否则等于把"某台机器的私有 CA"发给每个装 APK 的人。

## 2. 已验证（不是只改了文件）

**配置内容**（从打包好的 APK 里反查，`aapt2 dump xmltree`）：

- release：`cleartextTrafficPermitted=false`，trust-anchors = `system` + `user`（无内置 CA）
- debug：`cleartextTrafficPermitted=true`，trust-anchors = `system` + `user` + `@raw` 资源

**运行时**（真机，debug 包）：`base_url = https://127.0.0.1:3425/v1`（`adb reverse tcp:3425` 到本机 magpie），
三轮流式全部成功——`流结束：577 / 736 / 720 字，reason=stop，failure=null`。
说明 TLS 握手用的是**内置 magpie CA**（设备上没装任何用户证书），且 SAN 命中 `127.0.0.1`。

（顺便确认了 magpie 叶证书 SAN 覆盖：`desktop-0fov1bj`、`localhost`、`127.0.0.1`、`192.168.1.6` 等，
所以 `https://127.0.0.1:3425` 与 `https://192.168.1.6:3425` 都不会报主机名不匹配。）

## 3. release 想连自签网关怎么做

1. 把 `magpie-ca.crt` 传到手机（`dist/magpie-ca.crt`；就是 pem 改个后缀，方便系统识别成证书）；
2. 设置 → 安全 → 更多安全设置 → 加密与凭据 → 安装证书 → **CA 证书** → 仍然安装 → 选文件；
3. 装完在设置里能看到"用户证书"里有 `magpie CA DESKTOP-0FOV1BJ`；
4. App 里 `base_url` 填 `https://192.168.1.6:3425/v1`（局域网直连）即可。

注意：Android 7+ 默认**不信任**用户 CA，必须 App 自己在 network_security_config 里声明 `<certificates src="user"/>`——
这一步我们已经做了，所以上面的流程才有效。

## 4. 安全取舍（写清楚，别装糊涂）

- **允许 user CA** 意味着：任何能往手机"用户证书"里装 CA 的人（包括你自己、你装的可疑 App、以及拿到你手机的人）
  都可以对该 App 的 HTTPS 流量做中间人。这是自建网关/抓包调试的必要代价。
- 缓解：这个 App 不上架、只自用；release 不内置任何私有 CA；`cleartext` 在 release 仍然关闭。
- 如果哪天要上架或发给更多人：把 main 的 `user` 信任去掉，只留 `system`。
