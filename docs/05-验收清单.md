# AskFirst M1 验收清单

> 规则：**每一条都要在真机（<设备序列号>）上自己跑一遍并记录结果**，跑不过就不算 M1 完成。
> 不做"看起来能跑"的判断。验收记录写在本文件末尾的表格里。

---

## 0. 交付门（Definition of Done）

M1 完成 = 下面 5 条同时成立：

1. `.\gradlew.bat :app:assembleDebug` 成功；`:app:testDebugUnitTest` 全绿；
2. 真机上能完整跑通一次**真实的**思路确认（不是内置示例）：选场景 → 一句话 → ≥3 轮问答（其中有 1 次追问）
   → 「够了」→ 五栏单 → 复制成提示词 → 粘到别处能用；
3. 五栏单里**每一条都能点回它的出处**（哪一条回答生成的）；
4. 第 4 栏不足 2 条时，App 明确提示"还不能直接开工"，而不是照样欢快地出单；
5. 杀进程/重启后，未完成的会话还在（首页"上次未完成的思路"），点进去能接着答。

## 1. 手工用例（真机）

### M1-01 首启引导与 Key 配置
1. 卸载重装 → 首次打开应进「填模型」页：base_url / api_key / model 三输入 + 「测试连通」；
2. 故意填错 key 点测试 → 必须给出可读错误（401/超时/地址不合法分开提示），**不许转圈无反馈**；
3. 填对后测试通过 → 返回首页；
4. 设置页显示的 key 只能是 `••••abcd` 形式（截图存证）。
**判据**：任何界面/日志/导出文件里看不到完整 key（`adb logcat | Select-String "sk-"` 零命中）。

### M1-02 场景选择
首页列出 3 套出厂场景（技术方案/立项/复盘），点进去能看到该场景的问题清单（题目 + "为什么问"）。
**判据**：28 题全在（A1 9 + A2 10 + A3 9）；「为什么问」非空；不出现"门槛/状态机/覆盖"等内部词。

### M1-03 一句话开题
选「技术方案」→ 输入 20 字以内的一句话（例："首屏 4 秒太慢，想加缓存"）→ 开始。
**判据**：3 秒内出现 AI 的第一段流式输出（首字延迟），不是整段蹦出。

### M1-04 开放式提问优先（改动 #2）
观察 3 轮提问：
- 默认是**单个开放问题** + AI 给的一个「我的猜测」；
- 只有在答案确实分岔时才出现 2~4 个选项，且最后一项必须是「我自己写」；
- **不允许**出现"选择题轰炸"（连续 2 轮都是纯选项题即判失败）。
**判据**：拿 3 个不同模型各跑一次，记录各自表现（这是方案 §八 的"提问质量=模型质量"风险验证）。

### M1-05 追问优先于跳题（核心体验）
第 1 题故意只答三分之一（例：问"最痛的具体表现"，答"就是慢"）。
**判据**：下一轮 AI **不换话题**，而是换一种问法挖同一个点（"慢到什么程度？是首屏白屏 4 秒，还是滚动时卡？"），
并且 `covered` 里没有把该题标记为已覆盖。

### M1-06 确认单实时生长（改动 #6）
答完 2~3 轮后，中途打开确认单预览。
**判据**：已答内容已经在对应栏位里，空栏显示"（空）"，而不是只在最后一次性生成。

### M1-07 「够了」出单
点「够了，出确认单」。
**判据**：
- 出单为 5 栏、每栏是条目（不是大段散文）；
- 第 4 栏至少 2 条、动词开头；
- 每一条带出处（点条目能跳到那条回答）；
- 有 1 条是我没说过的内容 → 判**失败**（不编造是硬规则）。

### M1-08 五栏编辑
把第 2 栏某条改掉 → 退出重进 → 修改还在；再点"复制提示词"，复制出来的内容是**改后**的版本。

### M1-09 复制为提示词
点「复制成提示词」→ 粘贴到微信/备忘录，逐字比对模板：

```
我要做这件事：<intent>
目标与成功标准：<col1>
约束与前提：<col2>
已选定方案（放弃了 X，因为 Y）：<col3>
第一步：<col4>
这些我还没想清楚，别替我决定：<col5>

请基于以上内容直接开始 <任务>，不要重新问我已回答过的部分。
```
**判据**：六行标题一字不差；空栏不写"无"而是省略该行还是保留？——**保留标题、内容写"（还没定）"**，
避免下游模型把缺栏当成"没有约束"。

### M1-10 第 4 栏不足的拦截
故意只答 1 轮就点"够了"。
**判据**：出单后第 4 栏不足 2 条时，页面顶部有明确提示"这份单子还不能直接开工：第一步动作还不够具体"，
且提供「继续聊」按钮直接回到提问流。

### M1-11 断线/杀进程恢复
提问到一半，`adb shell am force-stop com.askfirst`，重进 App。
**判据**：首页顶部出现"上次未完成的思路 · <摘要>"，点进去问答全在，能接着答。

### M1-12 模型失败不丢数据
开飞行模式 → 发一条回答。
**判据**：我的回答已落库（重进还在）；UI 明确显示"网络/模型不可用，可重试"；
提供「本地先拼一份骨架」的降级出口（`SheetBuilder.fallback`），不静默丢数据。

## 2. 单元测试清单（纯 JVM，`app/src/test/java/com/askfirst/`）

| 测试类 | 覆盖点 | 必有用例 |
|---|---|---|
| `TurnParserTest` | JSON 容错 | 代码围栏包裹、尾逗号、缺字段、非法 JSON、超长截断、`covered` 里编造的 id |
| `StateMachineTest` | 状态转移 | gathering→needs_precision；needs_precision 不许跳 ready（四项未过时）；blocked→gathering；ready→gathering（用户改答案） |
| `PrecisionGateTest` | 四项检查 | 隐藏默认值命中"保存"；矛盾规则对（不登录 × 每人）；第 4 栏不足 2 条 → walkthrough_gap；目标漂移（intent 实词消失） |
| `SheetGrowerTest` | 实时生长 | 同文本去重、同栏 order 递增、无 source 的 delta 被丢弃（D4）、超 8 条截断 |
| `SheetValidatorTest` | 出单门 | 4 栏 <2 条 → blocking；第 5 栏空 → 允许；空栏 → warning |
| `PromptExporterTest` | 提示词模板 | **逐字**比对固定字符串；空栏填"（还没定）" |
| `PromptBuilderTest` | 上下文组装 | 六段顺序固定、缺段写"（空）"、超长从最早截断、system 里含"禁用内部术语"清单 |
| `SceneSeedTest` | 种子幂等 | 28 题、3 场景、required 标记正确、trigger 正则编译通过 |
| `SseParserTest` | 流解析 | `data: {...}` 多行、`[DONE]`、`data:` 后空行、畸形行不崩 |

**测试纪律**：引擎/解析/状态机**不许依赖 Android 类**（没有 `Context`、没有 `Log`），
否则就不能纯 JVM 跑。`android.util.Log` 一律换成 `core/Logx.kt` 里自己的接口。
