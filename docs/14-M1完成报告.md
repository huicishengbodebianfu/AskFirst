## 三、装与用（给亲友的一页纸）

1. **装**：把 `askfirst-0.1.0.apk` 传到手机 → 点安装（允许"安装未知应用"）。以后升级直接覆盖安装，不会丢数据。
2. **第一次打开**：会先看一页引导，点「去填 Key」→ 填三样：`base_url` / `api_key` / `model` → 点「测试连通」看到 ✅。
3. **用**：选场景 → 一句话说清要做的事 → 回答问题（每题都能「跳过」）→ 觉得够了点「够了，出确认单」→
   五栏单里可点条目改 → 点「复制成提示词」，粘给你平时用的 AI。
4. **钱与隐私**：模型费用走你自己的 Key；所有记录只在这台手机上；Key 在本机加密存储，不进日志、不进导出文件。
5. **闪退**：设置页底部「崩溃日志 → 把日志发给他」，用微信发出来即可。

**与原始方案的 6 处落地偏差**（都记在各自验收记录里）：
1. 五栏从"大文本列"改成"条目行（`sheet_item`）"——为实时生长与出处；
2. 首页把"场景选择 + 一句话"合成一屏（4 屏而非 5 屏）；
3. 引擎流式事件是**进度**（字符数），不是 JSON 原文——不能把 `{"state":…}` 甩给用户；
