## 3. 两个新坑

1. **Properties 读中文路径必踩编码坑**：`Properties.load(InputStream)` 按 ISO-8859-1 解，
   `storeFile=F:\安卓\…` 变成 `F:\å®å\…`，报 `Keystore file … not found`。
   修法：`keystorePropsFile.reader(Charsets.UTF_8).use { load(it) }`。
   （这跟 `local.properties` 那个坑是同一个根因，已写进 `docs/02`。）
2. **`adb install` 在 HONOR 上会被系统安装确认框卡死**，且这个框会连带把 `pm install` 一起堵住；
   连着两次 `adb install` 都 120s 超时。可行路径：`settings put global verifier_verify_adb_installs 0`
   + 用 `adb push` → `pm install`；实在卡住就重启设备。
