## 4. 这轮真机暴露并当场改掉的三件事

1. **模型不填 `covered`**（运行 1/2）：状态机永远停在 GATHERING，UI 里"够出单了"的提示出不来
   （停止权本来就在用户，所以不挡出单，但状态是错的）。改法：在 `engine_system.md` 末尾加"输出前最后一遍检查"，
   明确"covered 只有第一轮可以空，含糊回答也算已覆盖，把含糊点写进 precision_issues"。运行 3/4 起 `covered` 开始有值。
2. **第 4 栏"条数够但动作悬着"**（运行 1）：`canStart=true`，可动作写着"卡点未确认"。改法：
   `SheetValidator` 增加 `HedgedFirstSteps` 警告（未定/未确认/无法判断…），出单页会提示"第 4 栏里有 N 条动作还带着没定的前提"。不拦，但要明说。
3. **导出时出现「。；」**：条目自带句号再拼「；」。改法：`PromptExporter` 拼行前去掉尾标点，并加单测。

## 5. 结论（M1-04 / M1-05 / M1-07）

| 判据 | 结论 |
|---|---|
| M1-04 开放式提问优先 | ✅ 真实模型下默认给**开放问题 + 我的猜测**，一次 1~3 题；没出现选择题轰炸；`why` 都在 |
| M1-05 追问优先于跳题 | ✅ 运行 2/3 里连续 2~3 次追问同一处（"四秒里最难受的是哪一段"），clarify 明确说"我连着两次问你…你都还没答" |
| M1-07 不编造 | ✅ 运行 3 中模型在第 4 栏写"（本次对话未产出第一步动作）"而不是硬凑；第 5 栏保留 2~3 条真实未决 |
| M1-10 第 4 栏拦截 | ✅ 真实模型下 `canStart=false` + 横幅（运行 3） |

**模型推荐**：默认 `auto/glm-5.3`（JSON 合规、追问执着、会拒绝编造）；备选 `auto/gpt-6.1-sol`。
`auto/claude-sonnet-4-5` 目前走不通（网关上游问题），暂不推荐。
