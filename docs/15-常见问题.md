# 常见问题（亲友版）

> 这是发给用这个 App 的人看的一页。遇到问题时先在这里找，找不到再把「崩溃日志」发给他。

## 一、填 Key 相关

**Q：点「测试连通」报「模型服务不认这个 Key」怎么办？**
A：三个地方依次查：
1. Key 复制时有没有带空格或换行（粘完看有没有多余字符）；
2. `base_url` 是不是填到了 `/v1` 为止（例如 `https://api.deepseek.com/v1`，**不要**带 `/chat/completions`）；
3. 这个 Key 是不是已经删了/过期了 —— 去服务商控制台看一眼。

**Q：报「模型服务限流或额度用完了」？**
A：两件事选一件：等一会儿再试；或者去服务商控制台看余额。App 不代付、不转卖额度，用的就是你自己的。

**Q：报「等了 20 秒没回音」？**
A：手机上网络切换（Wi-Fi↔4G）最容易出这个。换个网络再点一次；如果一直这样，可能是那个服务商当时慢，换 `model` 或换个服务商。

**Q：`base_url` 到底填什么？**
A：填到 `/v1` 为止。各家示例：
- DeepSeek：`https://api.deepseek.com/v1`
- Kimi（月之暗面）：`https://api.moonshot.cn/v1`
- 智谱：`https://open.bigmodel.cn/api/paas/v4`
- 自己搭的网关：你网关的 OpenAI 兼容地址（很多人是 `http://内网IP:端口/v1`）

## 二、用的时候

**Q：它问的问题太啰嗦/太浅？**
A：这直接取决于你用的模型。同一个场景换 `model` 跑一遍对比一下，通常能差出一倍。App 里没有"调参数"的开关，因为提问质量不是靠温度调出来的。

**Q：我不想回答某一题？**
A：点「跳过这题」。它会换个角度问，或者换下一题，不会揪着不放。

**Q：什么时候可以停？**
A：任何时候点「够了，出确认单」。它不会拦你，只是如果第 4 栏（第一步动作）不到 2 条，会在单子顶部提醒"还不能直接开工"。

**Q：单子里的某条不对？**
A：直接点那一条就能改。改过的条目以后「重新出单」也不会被冲掉。每条右边的「看出处 N」能点开看他当时是哪几句话。

**Q：复制成提示词之后粘到哪？**
A：粘给你平时干活用的 AI（ChatGPT / Claude / DeepSeek 都行），或者粘进工单/文档。它的作用是让对方**别重新问你**已经回答过的事。

## 三、数据与隐私

**Q：我的记录存在哪？**
A：只存在这台手机上（App 私有目录的数据库里）。没有账号、没有云端、没有上传。

**Q：换手机会丢吗？**
A：会。M1 还没有导出/备份功能（M2 会做"导出 Markdown"）。换手机前记得把重要的单子「复制成提示词」存到别处。

**Q：Key 安全吗？**
A：Key 存在本机加密存储（Android Keystore + EncryptedSharedPreferences），不进日志、不进导出文件，界面上只显示后 4 位。但**手机本身丢了就是丢了**，建议在服务商控制台给 Key 设额度上限。

**Q：它会偷偷联网到别的地方吗？**
A：只有两处网络请求：你填的模型地址（发对话内容）；M6 的调研功能（还没做，做的时候会明确提示关键词会发给 GitHub）。

## 四、出问题了

**Q：闪退了怎么办？**
A：重新打开 → 设置页最下面「崩溃日志」→ 点「把日志发给他」→ 用微信发出来。
日志只有崩溃栈和机型，**没有任何对话内容和 Key**。

**Q：升级新版本会丢数据吗？**
A：不会。只要装的是同一个签名（他给你的包），直接覆盖安装，数据保留。

**Q：装不上/提示"签名不一致"？**
A：你手机上装过一个不同签名的旧包（比如他自己调试用的）。先卸载旧的再装新的——**注意这会把数据清掉**，先把要留的单子复制出去。
